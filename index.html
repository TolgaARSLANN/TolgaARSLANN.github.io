01 Feb 2025 — now Capstone · extended 2026

Pawfect Care

A pet care platform for health records, vaccines, medications and vet visits, plus a community blog.

  • Vaccine tracking with overdue and upcoming booster alerts, weight trends and appointments. Lazy-loaded React routes, light/dark themes, accessible forms.
  • 34-endpoint REST API with httpOnly SameSite=Strict JWT cookies, session revocation, brute-force rate limiting, helmet/CSP and server-side validation; data export and account deletion with a KVKK notice.
  • ~300 tests (170+ Jest/Supertest, 120+ Vitest/Testing Library) with ESLint on Node 22 and 24 in GitHub Actions. Frontend on Vercel, API on Render with MongoDB Atlas.

HavaUyarı

An air quality early warning system: 24-hour PM2.5 forecasts and alerts for 8 stations in 5 cities.

  • Ingests the Ministry's SİM station data and three Open-Meteo APIs; serves forecasts through a FastAPI service with an hourly cache and a Streamlit dashboard.
  • PostgreSQL storage for forecasts and alert history (SQLAlchemy, Alembic) with docker-compose; 144 tests, including PostgreSQL integration tests, run in CI.

Card Fraud Detection

A scoring service that returns a decision and its top 3 reasons for every transaction.

  • FastAPI service and Streamlit panel for a LightGBM model trained on 1.85M synthetic transactions (Kaggle Sparkov); a cost-based alert rule caught 98% of fraud value.
  • Containerized with Docker; found and fixed per-session memory growth (+205 MB over 3 sessions) with docker stats under a 2 CPU / 3 GB limit, then published a public demo.
